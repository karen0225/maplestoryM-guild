# 專案說明（王團排程表）

單一靜態網頁 `index.html`，內含全部 HTML/CSS/JS，無建置流程、無外部套件。

## 工作規範

- **功能實作完成後不需額外主動跑測試**（例如啟動瀏覽器、跑 syntax check 等），除非使用者明確要求。
- **資料相容性優先**：所有資料以 JSON 格式儲存於 `localStorage`（見 `STORAGE_KEY`），並可透過「匯出/匯入 JSON」在不同時間、不同版本之間轉移。
  - 修改資料結構（例如 `state.members` / `state.raids` / `raid.slots` 的欄位名稱、型別、必填與否）時，必須確保新版程式碼仍能正確讀取「舊版已儲存的 JSON」，避免使用者既有資料在升級後解析失敗或跑版。
  - 若某個修改**必須**變更既有資料結構、可能導致舊版 JSON 不相容（無法安全地向下相容讀取），**先告知使用者影響範圍與遷移方式，取得同意後才進行修改**，不可未經同意逕自變更資料格式。
  - 純新增可選欄位（optional，帶預設值、舊資料沒有該欄位時仍可正常運作）不算破壞相容性，可直接進行。
